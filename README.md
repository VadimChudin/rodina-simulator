# ЛПЗС «Родина» — 2D-эмулятор пульта

Учебный тренажёр линии очистки зерна. Браузер рисует мнемосхему,
крутит нории/шнеки, сыплет зерно по выбранному маршруту.
Сервер на FastAPI держит «настоящее» состояние линии (задержки, ТО,
датчики, журнал). Если сервера нет — страница работает сама.

## Запуск

```bash
cd lpzs_emulation
python3 -m pip install -r requirements.txt
python3 -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

Открыть http://127.0.0.1:8000

Либо просто открыть `frontend/index.html` в браузере — локальный режим.

## Как пользоваться

1. Красная кнопка **АВАРИЙНЫЙ СТОП** в шапке — отожмите (линия по умолчанию в аварии).
2. Справа **ПУСК РЕЖИМА** — механизмы стартуют с хвоста к голове.
3. Зерно идёт из ямы → нории → триеры/пневмостол → бункер В.
4. Клик по механизму — пуск/стоп, задержки, ТО, датчики.
5. Блок **Тренажёр аварий** — ДКС / сход ленты / подпор, линия встаёт.
6. **Сброс аварии** внизу — квитирование (после снятия стопа).

Маршруты очистки (как в приложении 5):

- через БТ и СП
- мимо БТ, через СП
- через БТ, мимо СП
- мимо БТ и мимо СП

## Как устроен код

```
backend/plant.py   — модель линии: машины, маршруты, зерно, аварии
backend/main.py    — FastAPI: REST + WebSocket /ws (снимок 10 раз/с)
frontend/index.html — каркас пульта (схема + боковая панель)
frontend/css/style.css
frontend/js/app.js  — отрисовка SVG, локальный тик, окна механизмов
```

**Порядок пуска режима:** хвост → голова, с паузой `delay_start`.
Так продукт не падает на стоящий узел. Стоп — наоборот, с головы.

**Зерно** — частицы по рёбрам графа (`EDGES` в JS / `_active_edges` в Python).
Ребро живое только если все машины маршрута в работе.

**Датчики** ДКС / ДСЛ / ДП на нориях и шнеках. Срабатывание = авария + останов линии.

Фронт сначала пытается открыть `/api/state` и `/ws`. Если сервера нет —
крутит ту же логику у себя в `tick()`.

## Что моделируется

- **Каскадный пуск и останов.** Пуск идёт с хвоста линии к голове, останов — наоборот.
  Шаг каскада задаётся в настройках.
- **Движение продукта.** У каждого механизма есть наполнение продуктом 0…100 %.
  Значение течёт от головы линии к хвосту, поэтому при закрытии подачи или опустевшей
  завальной яме механизмы опорожняются волной, а не разом. Видно в слое зерна на схеме
  и в полосе материального потока на странице «Параметры».
- **Подвижные детали.** Витки шнеков, роторы вентиляторов, барабаны триеров, решётные
  станы на эксцентрике, шлюзовые затворы, барабаны норий, закрутка в циклонах.
  Всё крутится с инерцией: после стопа детали докручиваются, а не замирают мгновенно.
- **Материальный баланс.** Завальная яма пустеет, чистое зерно копится в бункере В,
  относы аспирации — в бункере А, сход с решёт и триеров — в бункере Б.
- **ДВУ.** При заполнении бункера выдержка времени, затем останов подачи или нории.
- **Аварии.** ДКС, сход ленты, подпор, защита двигателя. Пока причина не снята,
  квитирование невозможно — причины видны на странице «Аварии».

## Страницы

| Вкладка | Что на ней |
|---|---|
| Мнемосхема | Схема линии, журнал, график, выбранный механизм |
| Оборудование | Таблица всех механизмов: состояние, ток, обороты, наработка, ТО, пуск и стоп |
| Параметры | Карточки параметров, уровни семи ёмкостей, полоса материального потока, тренды |
| Аварии | Сводка, активные причины со снятием, журнал и архив сообщений |
| Настройки | Задержки ДВУ, шаги каскада, маршрут по умолчанию, учётная запись, отображение, модель |

Настройки сохраняются в браузере и подхватываются при следующем открытии.
